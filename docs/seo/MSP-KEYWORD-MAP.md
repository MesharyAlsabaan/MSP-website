# MSP Keyword Map — Saudi Arabia

Date: 2026-10-15 · Market: Saudi Arabia (Riyadh first), English and Arabic · Status: **qualitative**

**Method.** No search-volume, difficulty or ranking data was used: Google Search Console and keyword tools were not connected when this was written. Keywords come from the management brief, MSP's verified services and portfolio, and how Saudi clients describe these services. Search volumes are deliberately not given. Validate this map against Search Console queries (Performance → Queries, filtered to Saudi Arabia) after 8–12 weeks of indexing, and re-assign pages if the data disagrees.

**Rule.** One primary keyword per page and language, so pages don't compete with each other for the same query. Supporting terms may repeat across pages; primary keywords may not.

## Competing-intent risks

- **Services page carries five primary keywords** (#5, #6, #15–18) because no service subpages exist yet. This is acceptable short-term; it is the main reason to approve the proposed subpages below.
- **Projects page carries villa and commercial intents** (#9, #10, #13, #14) through filters whose URLs (`?sector=`) are canonicalised to `/projects`. Filtered views cannot rank on their own; dedicated landing pages would be needed.
- **"Hotel design"** could be split between the Madinah Hotel project and the Madinah insight. The project page is primary; the article links to it (it already does via its related-project CTA).
